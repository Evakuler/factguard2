# FactGuard 2.1 — перевірка достовірності новин зі штучним інтелектом

Розширення для Google Chrome + локальний Python-сервер. Перевіряє новину з чотирьох боків:

| Блок | Що перевіряє | Потрібен сервер? |
|---|---|---|
| **Джерело** | Хто публікує: білий список ІМІ, фактчекери, державні сайти, підробки під ЗМІ (`suspilne-news.top`), вік домену, база фішингу, **ваші білий і чорний списки** | ні |
| **Подача** | Ознаки маніпуляції: КАПСЛОК, «шок», анонімні «джерела», «поширте, поки не видалили», емоційні слова, немає автора/дати/посилань | ні |
| **Перевірка на інших сайтах** | Чи пишуть про це інші ЗМІ та чи не спростовували це фактчекери (Google Новини + DuckDuckGo) | **так** |
| **🤖 ШІ-аналіз** | Модель ШІ читає тексти статей інших сайтів і робить висновок: вердикт, впевненість, ключові твердження, прийоми маніпуляції | **так + ключ ШІ** |

Крім того, на кожному сайті розширення тихо перевіряє фішинг і показує червоний банер на небезпечних сторінках
та на сайтах з вашого чорного списку.

---

## Встановлення

### 1. Розширення (2 хвилини)

1. Розпакуйте архів. Має вийти папка `FactGuard` з файлом `manifest.json` усередині.
2. Відкрийте в Chrome адресу **`chrome://extensions`**.
3. Увімкніть **«Режим розробника»** (праворуч угорі).
4. Натисніть **«Завантажити розпаковане розширення»** і виберіть папку `FactGuard`.
5. Закріпіть іконку: значок пазла 🧩 праворуч від адресного рядка → 📌 біля FactGuard.
6. Оновіть (F5) вкладки, які були відкриті до встановлення.

> Якщо ви оновлюєте стару версію: на `chrome://extensions` натисніть ⟳ («Оновити») на картці FactGuard і оновіть відкриті вкладки.

Уже на цьому етапі працюють блоки «Джерело» і «Подача», захист від фішингу, білий і чорний списки.

### 2. Python-сервер (перевірка на інших сайтах + ШІ)

Потрібен **Python 3.10 або новіший** ([python.org/downloads](https://www.python.org/downloads/)).
На Windows під час встановлення Python обов'язково поставте галочку **«Add Python to PATH»**.

| Система | Що зробити |
|---|---|
| **Windows** | Двічі клацніть `server\start-server.bat` |
| **macOS** | Права кнопка на `server/start-server.command` → **«Відкрити»** → «Відкрити» (лише перший раз) |
| **Linux** | У терміналі: `bash server/start-server.command` |

Перший запуск встановлює бібліотеки (1–2 хвилини) і створює файл `server/.env` для ключа ШІ.
Сервер працює, коли у вікні видно `Uvicorn running on http://127.0.0.1:8000`.
**Вікно не закривайте**, зупинка — `Ctrl+C`.

У віконці розширення внизу має з'явитися **«● Сервер працює»** зеленим.

**Запуск вручну через термінал** (якщо скрипт не спрацював):

```bash
cd FactGuard/server
python -m venv venv                 # macOS/Linux: python3 -m venv venv
venv\Scripts\activate               # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env              # macOS/Linux: cp .env.example .env
python main.py
```

Перевірка: відкрийте http://127.0.0.1:8000/api/health → має бути `{"status":"ok", ... "ai": {...}}`.
Документація API: http://127.0.0.1:8000/docs

### 3. Підключення ШІ

ШІ-аналіз працює з будь-якою моделлю з OpenAI-сумісним API. Найпростіше — **Google Gemini (безкоштовно)**:

1. Відкрийте https://aistudio.google.com/apikey, увійдіть через Google-акаунт → **«Create API key»** → скопіюйте ключ.
2. Відкрийте файл `server/.env` будь-яким текстовим редактором (Блокнот). Якщо його немає — скопіюйте `server/.env.example` під назвою `.env`.
3. Знайдіть блок «Варіант 1», приберіть `#` на початку рядків і вставте ключ:
   ```
   AI_PROVIDER=gemini
   AI_API_KEY=AIza...ваш_ключ
   AI_MODEL=gemini-3.8-flash
   ```
4. Збережіть файл і **перезапустіть сервер** (закрити вікно → знову `start-server`).
5. Перевірте: у віконці розширення внизу — **«● ШІ: Google Gemini»** зеленим.
   Або в терміналі в папці `server`: `venv\Scripts\python ai.py` (macOS/Linux: `venv/bin/python ai.py`) → `✓ ШІ працює`.

Інші варіанти (усі описані у `server/.env.example`):

| AI_PROVIDER | Що це | Ціна | Ключ |
|---|---|---|---|
| `gemini` | Google Gemini | безкоштовний ліміт | https://aistudio.google.com/apikey |
| `groq` | Llama 3.3 на Groq, дуже швидко | безкоштовний ліміт | https://console.groq.com/keys |
| `openai` | GPT-4o-mini | платно (копійки за запит) | https://platform.openai.com/api-keys |
| `ollama` | локальна модель на вашому ПК, без інтернету | безкоштовно | не потрібен; встановіть [Ollama](https://ollama.com) і виконайте `ollama pull qwen2.5:7b` |
| `custom` | будь-що OpenAI-сумісне (OpenRouter, LM Studio) | — | задайте ще `AI_BASE_URL` |

ШІ можна вимкнути у віконці розширення: вкладка «Новина» → перемикач «🤖 ШІ-аналіз новини».

**Типові помилки ШІ**

| Повідомлення | Що робити |
|---|---|
| «ШІ не підключено: у файлі server/.env не задано AI_PROVIDER» | Не прибрали `#` перед рядками або файл називається `.env.txt` (у Windows увімкніть показ розширень файлів) |
| «Ключ ШІ не підходить (401/403)» | Ключ скопійовано не повністю або з пробілом |
| «Перевищено ліміт запитів (429)» | Безкоштовний ліміт вичерпано — зачекайте хвилину або візьміть інший провайдер |
| «Не вдалося з'єднатися з сервісом ШІ» | Немає інтернету / для Ollama — не запущено програму Ollama |
| «Сервіс ШІ зараз перевантажений (помилка 503)» | Модель Google тимчасово перевантажена (не помилка FactGuard). Сервер сам повторює запит і пробує резервні моделі (`gemini-3.6-flash`, `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`). Якщо перевантажені всі — зачекайте 1–2 хв або підключіть інший сервіс (наприклад, Groq) |
| «Сервіс ШІ не відповів за … с» | Модель перевантажена або «думає» задовго. Сервер уже сам повторює запит коротшим. Якщо помилка лишається — у `server/.env` задайте `AI_MODEL=gemini-3.5-flash-lite` (швидша) або `AI_TIMEOUT=180`, перезапустіть сервер |

## Як користуватися

- **Перевірити статтю:** відкрийте новину → іконка FactGuard → «Перевірити новину на цій сторінці».
  Результат з'явиться і у віконці, і в панелі праворуч на сторінці (закривається хрестиком або Esc).
  Спочатку з'являються «Джерело» і «Подача», за кілька секунд — «Перевірка на інших сайтах», потім — «ШІ-аналіз» (до 1 хв).
- **Перевірити окрему фразу:** виділіть речення → права кнопка миші → **«Перевірити новину на фактчекінг»**.
- **Перевірити посилання на фішинг:** вкладка «Сайт» → поле «Перевірити посилання».
- **Білий і чорний списки:** вкладка «Сайт» → «Мої списки сайтів».
  - ✅ **Білий список** — сайти, яким ви довіряєте: попередження про фішинг на них не з'являються.
  - ⛔ **Чорний список** — сайти, які ви вважаєте небезпечними: на них завжди з'являється червоний банер.
  - Можна вписати `example.com` або вставити повне посилання — збережеться лише назва сайту. Запис діє і на піддомени.
  - Додати поточний сайт — кнопками «✅ Довіряю» / «⛔ До чорного списку» під результатом перевірки.
  - Сайт не може бути в обох списках одночасно. База фішингу PhishDestroy сильніша за білий список
    (підтверджений фішинг завжди позначається), а ваш чорний список — сильніший за все.
  - Списки синхронізуються між комп'ютерами з тим самим акаунтом Chrome.
- **Значок на іконці:** `✓` — підтверджено, `?` — недостатньо даних, `!` жовтий — схожі фейки спростовували,
  `!` червоний — спростовано або фішинговий сайт, `×` — сервер недоступний.

### Що означають вердикти

**Перевірка на інших сайтах:**

| Вердикт | Коли |
|---|---|
| **Спростовано** | Фактчекери (StopFake, VoxCheck, ЦПД…) або перевірене ЗМІ назвали фейком *саме це* твердження |
| **Підтверджують незалежні ЗМІ** | Про це пишуть щонайменше 2 незалежні джерела, з них хоча б одне перевірене |
| **Схожі твердження спростовували** | Фактчекери спростовували схожі історії на ту саму тему — варто перевірити уважніше |
| **Лише неперевірені сайти** | Пишуть тільки невідомі сайти (фейки часто передруковують десятки сайтів) |
| **Інші ЗМІ не пишуть** | Схожих публікацій не знайдено — новина нічим не підтверджена |

**ШІ-аналіз:** Правда · Ймовірно правда · Не вдалося перевірити · Маніпуляція / напівправда · Ймовірно фейк · Фейк —
плюс впевненість у відсотках і пояснення для кожного ключового твердження.

Програма **не може напевно встановити правду**: вона показує, хто ще про це пише, як подано матеріал і що думає ШІ.
Остаточне рішення — за людиною.

## Як це працює

```
 Сторінка з новиною              Розширення (Chrome)                    Python-сервер (127.0.0.1:8000)
┌────────────────┐ заголовок, ┌──────────────────────────┐ /api/verify-news ┌───────────────────────────────┐
│ content.js     │─текст, URL▶│ background.js            │─────────────────▶│ main.py                       │
│ • витягує      │            │ • FG_SOURCE: джерело,    │                  │ 1. ключові слова              │
│   статтю       │            │   фішинг, ваші списки    │◀──── вердикт ────│ 2. Google Новини + DuckDuckGo │
│ • аналіз       │            │ • FG_VERIFY: пошук       │                  │ 3. хто пише? (ІМІ, фактчекери)│
│   подачі       │◀─результат─│ • FG_AI: ШІ-аналіз       │ /api/ai-check    │ ai.py                         │
│ • панель       │            │ • значок на іконці       │─────────────────▶│ 4. читає статті інших сайтів  │
└────────────────┘            └──────────────────────────┘◀── висновок ШІ ──│ 5. питає модель ШІ (Gemini…)  │
                                                                            └───────────────────────────────┘
                   data/trusted-media.json — спільний довідник джерел для розширення і сервера
```

**Сервер (`server/main.py`, `server/ai.py`):**
1. Із заголовка виділяє ключові слова (без службових «і», «що», «the»).
2. Паралельно робить чотири пошуки: Google Новини (RSS, без ключа), новини DuckDuckGo, звичайний DuckDuckGo
   і «3 найзмістовніші слова + фейк». Якщо один пошуковик недоступний — працюють інші.
3. Для кожного результату рахує схожість: яка частка ключових слів у ньому є (з урахуванням закінчень).
4. Визначає, хто це написав: перевірене ЗМІ, фактчекер, державний сайт чи невідомий сайт. Соцмережі та власний сайт статті не рахуються.
5. Виносить вердикт за таблицею вище.
6. ШІ-аналіз: завантажує до 4 знайдених статей (спершу фактчекерів і перевірених ЗМІ), бере з них основний текст
   і передає моделі разом із новиною та результатами пошуку. Модель повертає JSON (вердикт, впевненість, твердження,
   маніпуляції, порада), сервер перевіряє його і передає в розширення. Результати кешуються на 30 хвилин.

Необов'язково: якщо в `server/.env` задати `GOOGLE_FACTCHECK_API_KEY` (безкоштовний ключ Google Fact Check Tools API),
сервер додатково шукатиме перевірки фактів у світовій базі Google.

## Оцінювання ефективності

Для розділу «Оцінювання» є скрипт `server/evaluate.py`:

1. Заповніть `server/dataset.csv` (колонки `title,label`, де `label` = `fake` або `true`):
   ~50 фейків з архівів StopFake / VoxCheck і ~50 правдивих новин із видань білого списку ІМІ.
2. У папці `server`: `venv\Scripts\python evaluate.py --ai` (macOS/Linux: `venv/bin/python evaluate.py --ai`).
   Без `--ai` — лише пошук на інших сайтах (для порівняння «з ШІ / без ШІ»).
3. Скрипт виведе покриття, accuracy, precision, recall і F1 для класу «фейк» та середній час перевірки,
   а детальні результати збереже в `evaluation_results.csv` (відкривається в Excel).

## Тести

- **Розширення:** іконка → «Самоперевірка» → має бути «Пройдено 75 з 75».
- **Сервер:** у папці `server` після першого запуску:
  `venv\Scripts\python -m unittest test_main.py` (macOS/Linux: `venv/bin/python -m unittest test_main.py`) → `OK`.
  Інтернет і ключ ШІ для тестів не потрібні: пошук і модель підміняються «фальшивими».

## Довідник джерел

`data/trusted-media.json` містить білий список ІМІ за I півріччя 2026 року (18 видань), міжнародні агенції та фактчекерів.
ІМІ оновлює список двічі на рік — актуальний дивіться на [imi.org.ua](https://imi.org.ua) і просто допишіть/видаліть рядки у файлі.

## Приватність

- Подача та джерело аналізуються локально, у браузері. Білий і чорний списки зберігаються лише у вашому Chrome.
- На сервер (на вашому ж комп'ютері) йде заголовок і текст; сервер шукає в Google Новинах і DuckDuckGo **лише ключові слова** заголовка.
- Якщо ШІ підключено, заголовок, уривок тексту (до 2500 символів) і знайдені матеріали надсилаються вибраному
  сервісу ШІ (Google, Groq, OpenAI). З Ollama все залишається на вашому комп'ютері.
- Вік домену запитується в `rdap.org` для сайтів, які ви самі перевіряєте, або для вже підозрілих.
- Файл `server/.env` з ключем ШІ не викладайте на GitHub (він уже в `.gitignore`).

## Історія проєкту

FactGuard 2.0 об'єднує два проєкти:

- **FactGuard 1.0 (ідея та код учениці):** перехресна перевірка новини в інших ЗМІ через Python-сервер,
  контекстне меню для виділеного тексту, плаваюча панель із результатом, ін'єкція скриптів у вкладки,
  відкриті до встановлення, зрозумілі повідомлення про помилки. Її `background.js` і `content.js` лягли в основу.
- **PhishGuard 2.0:** захист від фішингу (база PhishDestroy, тайпсквотинг, вік домену), аналіз ознак
  маніпуляції в тексті, автоматичні тести, іконки.

Що дописано під час об'єднання: сервер `main.py` і логіка вердикту (файлів сервера не було в репозиторії),
`ui.js`, popup, блок «Джерело» з білим списком ІМІ, пошук спростувань у фактчекерів, режим перевірки
лише заголовка для виділених фраз, скрипти запуску сервера в один клік, тести сервера.

**Версія 2.1:** пошук через Google Новини (крім DuckDuckGo) і паралельні запити, ШІ-аналіз з читанням статей
інших сайтів (`ai.py`), білий і чорний списки у вкладці «Сайт», синхронізація результату між панеллю і віконцем,
